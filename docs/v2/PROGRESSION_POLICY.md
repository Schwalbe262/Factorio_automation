# 진행 대기와 선행 준비

`observe`는 철판·구리판·석탄·돌에 대해 현재 건설 예산, 회수 가능한 재고, 관측 생산·소비 속도와 추가 생산 설비 비용을 비교합니다. 재고가 이미 충분하면 수집하거나 다음 진도로 넘어가고, 출력 막힘은 하류부터 해결합니다. 확장 후보는 최대 두 셀이며 다른 원료까지 실제로 지불할 수 있어야 합니다. 이 결과는 Luna의 작업 선택을 돕는 근거이며 생산 속도 보장은 아닙니다.

Luna는 승인된 다음 작업에 필요한 해금된 건설품을 `prepare_components`로 준비할 수 있습니다. 목표는 건설품 1~8종의 절대 재고 1~50개입니다. 현재 건설 원료 예산을 먼저 보존하고, 기존 수집·제작 함수만 실행합니다. 미래 기술의 설비를 미리 지을 수 없습니다.

실행기가 현재 입력 공급을 끝냈고 네이티브 연구·생산이 스스로 진행됨을 증명한 대기에는 `autonomous_wait`와 `background_work_safe`가 붙습니다. 승인된 준비 작업만 안전한 행동 경계에서 실행할 수 있습니다. 현재 표시는 정상 연구와 유한 초기 과학 배치에 구현되어 있습니다. 모든 대기 유형을 검증했다는 뜻은 아닙니다. 과학 배치 선행 생산의 첫 지원 경로는 [전기 채광 연구 → 물류](SCIENCE_PIPELINE.md)입니다.

극초반 `quiet` 방어 목표는 신규 포탑 0개입니다. 산업 구역도 현재 생산 시설과 예정지 주변 96타일에서 위협이 없을 때 방어 선행 조건을 미룹니다. 이 판단은 무장 방어 범위를 증명한 것으로 기록하지 않습니다. 적 접근, 실제 피해, 기술 단계 변화로 조건이 달라지면 다시 방어를 요구합니다. 등록된 세계·설비·구역 경계와 미확정 행동은 기존 검사를 유지합니다.

현재 검증은 원료 보호, 실제 이동 영수증, 재시작, 연구 해금, 작업 전환, 조용한 지역의 방어 생략과 위협 재출현을 포함합니다. 새 맵 1시간 재현이나 Luna 단독 로켓 성공은 아직 검증하지 않았습니다.
