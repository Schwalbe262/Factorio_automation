# Prospective external transport reservations

Producer rectangles protect empty machine expansion space. Accepted external
feeds and power paths also reserve their actual prospective footprints, including
the full buried span of unfinished underground pairs. Future belts and pipes
retain one adjacent tile to prevent incidental side feeds and fluid connections.
These reservations apply to solid and fluid routing, and Chemical/Advanced core
selection. Existing native hardware uses the usual exact crossing/preflight
checks; no imaginary native entity or unit is inserted into observations.

Neither source nor destination can erase a foreign prospective keepout merely
by becoming the new route endpoint. Ordinary material/resource/mining keepouts,
whole producer reservations and fixed port continuations remain in force.

A controller replanning its own unbuilt receiver can pass
`released_unbuilt_receiver={'block': name, 'plan_revision': sha256}` to the belt
planner. The canonical JSON revision must match the exact registered board plan,
and the destination must be that block's registered typed input. This releases
only its external prospective hardware. Its core, future machine reservation,
fixed aprons, other blocks and actual native hardware stay protected. Replanning
controllers must separately prove that no owned consumer construction started,
preserve exact sources and publish the replacement plan resumably before use.

Development evidence: newly built Plastic belt `(110.5,-48.5) E` crossed an
accepted unbuilt Engine steel feed at that position facing north. Engine is held;
the existing Plastic asset must be preserved and must never become an Engine
binding. Focused regressions cover the prospective external footprint/tunnel,
neighbor cells, endpoint collision, exact receiver release and stale revision,
plus Chemical and Advanced core rejection. A proposed route still requires its
fresh whole native preflight before actual construction.
